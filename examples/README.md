# TATAMI Examples & Case Studies

This folder contains case studies and examples of models written in the TATAMI language. TATAMI is a visual programming language designed for modeling tokenomics and decentralized systems. Each subdirectory represents a specific case study, containing its visual XML model and, where applicable, the generated Solidity implementation.

The examples are organized as follows:

